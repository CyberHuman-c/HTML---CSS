# Frontend Quiz App Project

A fast, responsive web app quiz for frontend Developers to test their knowledge on HTML, CSS, and JavaScript.

## Features

- **Dynamic Question Engine**: Renders the questions and options dynamically using JavaScript.
- **Instant Feedback**: Indicates for correct and incorrect upon selection and displays it immediately.
- **Responsive Design**: Styled with CSS Flexbox and Grid for optimal viewing on all devices.
- **High Score Saved**: Saves the highest score of a user locally using 'localStorage' API on JavaScript. 

## Tech Used

### Frontend
- **HTML5**: Semantic Layouts.
- **CSS3**:  CSS Flexbox, and Grid.
- **JavaScript (ES6+)**: DOM Manipulation, and 'localStorage' API.

### Development Tools
- **VS Code**: The Code Editor.
- **Git & GitHub**: Version Control, and Deployment.
